# 织音 · UI 决议（2026-11-16）

四条已定，作为实现的输入。UI 先行，实现在决议之后。

## 已定决策

| 编号 | 决策 | 含义 |
|---|---|---|
| D-1 | **安装/卸载写盘** | 安装 = 写入 `~/.dsh/skills` 或 `<项目>/.dsh/skills`；卸载 = 移入归档目录（可恢复），不是直接删除 |
| D-2 | **技能包是启用单位** | 启用一个包 = 批量启停它的成员；**允许多包并存**（并集），不是互斥单选 |
| D-3 | **停用 = 完全不可见** | 模型目录不列、`skill` 工具拒绝、`/` 菜单也不出现。AI Vault 当前的实现是把停用技能移进归档目录 |
| D-4 | **入口只在设置** | DSH → 设置 → 织音。不做侧栏常驻入口 |

## 页面骨架（内容列约 700px）

1. **状态条**：已启用 N · 已停用 N · 目录字符数 / 预算 8000（超限红条）· 观测完整 · 上次扫描时间 ·〔重新扫描〕
2. **工具栏**：搜索 · 列表/卡片切换 · 分段（全部 / 已启用 / 已停用 / 技能包）·〔+ 安装〕（文件夹 / zip / URL / 新建）·〔导出〕
3. **内容区（三视图同位置切换）**
   - 列表（默认）：按技能包分组；组头 = 包名 · 成员数 · 组目录成本 · 整组开关
   - 卡片：2 列（320×120）
   - 技能包：包卡片，一键启停整组
4. **管理成员弹窗**：左栏包列表（新建/改名/复制/删除/拖拽排序），右栏技能清单（搜索 + 包内/包外开关 + 全不选/全部/保存）
5. **详情抽屉**：`SKILL.md` 正文只读渲染（不落盘）· frontmatter · 路径 · 来源 · 可用面 · 字符成本 · 所属包

## 与 AI Vault 的差异

- 4 列卡片 → 2 列 + 默认列表（内容列只有约 700px，175 个技能）
- 独立窗口 + 左导航 → 设置里一页 + 页内分段
- 检查更新 / 版本回退 / 发现市场 → v1 不做
- Token 估算徽标 → 目录字符数（DSH 目录进系统提示，字符数可计量）
